# blend: the learned-blend pipeline (`Settings::v3Blend`: 0 = the rule, 1 = Fluidity, 2 = Consistency; the nets in the build are `blend/weights/forza-rx9070xt/C.npz` and `blend/weights/ar4/C.npz`, the other weight sets stay in `blend/weights/` as training history; table in `blend/weights/README.md`)

An experiment: three tiny per-pixel nets ("A", "B", "C") replace the hand-written tap weights of V3's synthesis (`gpu/V3.md`, "As built (learned blend, experiment)"). The training here still produces the nets A, B and C of every set; only the net C of two sets is in the build (Fluidity, Consistency).
Everything here produces data or numbers; the library only holds the final weights (`gpu/shaders/v3_blend_weights.glsl`, generated by `gpu/ml/blend/export_glsl.py`).
`$BLEND` = `/home/mo/DieGanzeSau/AI_Video_Training_Data/blend` (override with the environment variable `BLEND`). Long commands: `ccorral -- CMD`; every GPU call: `flock $HOME/tmp/fg-handoff/gpu.lock ccorral -- CMD`.

## Rerun, in order
1. Data (`cd blend/data`; details in its README): `extract.py CLIP` for every clip, `build_manifest.py`, `dump.py` (needs `fgtest` from `cd gpu && meson setup build-blend && ninja -C build-blend`),
   `oracle.py`, `measure.py`. The real frames are the owner's footage cuts (`footage/cuts/*.mp4`, `footage/PROBE.md`): the even frames are the inputs, the odd frame in between is the target.
2. Teacher (`cd blend/teacher`): `teacher.py mids --budget-sec 100`, in chunks, then `dump.py --kind teacher` (data README, "Dump for samples with teacher targets").
3. Training (`cd blend/train`, the PyTorch interpreter named in its README): `build_cache.py real --cap 8192`, `build_cache.py teacher --cap 2048`, `train.py $BLEND/train/out/real_only`,
   `train.py $BLEND/train/out/with_teacher --teacher`, `score.py`. The weights used by the library are `$BLEND/train/out/{A,B,C}.npz`.
4. Export: `python3 gpu/ml/blend/export_glsl.py FLUIDITY.npz CONSISTENCY.npz [-o ...]` (one six-choice net C `.npz` per value, in value order: the first = `v3Blend` 1, the next = 2; the committed header is made from the two files in `blend/weights/README.md`; writes the header in `gpu/shaders/`; commit that file alone). A new net replaces a file in that list or is appended to it, with `kV3BlendMax` raised to match.
   Check against the shader: `fgtest --set algo=v3,v3Blend=N (1 or 2) --v3weights PREFIX --v3wmax N ...` for N = 0 and N, then `ref.py RULE_DUMP.bin NET_DUMP.bin WEIGHTS.npz W H prev.rgba curr.rgba STRIDE [rgb10]` (STRIDE is the stride `fgtest` prints in its `V3WEIGHTS` line) (max difference below 1e-3; 1e-6 measured).
5. Comparison clips (`blend/render`, system python3 with numpy, ffmpeg): per clip, in this order
   `python3 blend/render/render.py extract CLIP` (240 consecutive source frames to `$BLEND/render/raw/CLIP`; picks the stretch with the fewest repeated frames),
   `... gen CLIP [SECONDS]` (fgtest, both tests, four versions; resumable, rerun until it exits 0),
   `... score CLIP`, `... video CLIP`, `... clean CLIP` (deletes the raw frames), and once `... report` (`$BLEND/render/scores.md`, `scores.json`).
   Clips: `racing_forza6_a`, `_b`, `_c`, `fps_cs2_a`, `minecraft_rtx_a`, `indie_schedule1_a`, `realworld_portland_walk_a`.
